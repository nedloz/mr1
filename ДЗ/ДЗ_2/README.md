# Как рассчитать ошибки модели вручную

Для модели $\hat y_i=b_0+b_1x_{1i}+b_2x_{2i}$ на выборке из $n$ наблюдений. Считаем отдельно для данных с выбросами и без них. Нули в $y$ заранее заменены единицами. $k$ — число оцениваемых параметров вместе с константой (здесь $k=3$).

## Шаг 0. Подготовка столбцов (Excel / любая таблица)
1. $\hat y_i$ — прогноз по уравнению регрессии.
2. $e_i=y_i-\hat y_i$ — остаток.
3. $e_i^2$, $|e_i|$, $|e_i/y_i|$ — столбцы для ошибок.
4. $(y_i-\bar y)^2$ — столбец для $TSS$.
5. $\big(\ln(\hat y_i+1)-\ln(y_i+1)\big)^2$ — столбец для RMSLE.

Суммы: $ESS=\sum e_i^2$, $TSS=\sum(y_i-\bar y)^2$.

## Шаг 1. Формулы

| Метрика | Формула | Excel |
|---|---|---|
| MSE | $\dfrac{ESS}{n}$ | `=СУММ(e²)/n` |
| RMSE | $\sqrt{MSE}$ | `=КОРЕНЬ(MSE)` |
| MAE | $\dfrac1n\sum\lvert e_i\rvert$ | `=СРЗНАЧ(\|e\|)` |
| MAPE | $\dfrac{100\%}{n}\sum\left\lvert\dfrac{e_i}{y_i}\right\rvert$ | `=СРЗНАЧ(\|e/y\|)*100` |
| RMSLE | $\sqrt{\dfrac1n\sum\big(\ln(\hat y_i+1)-\ln(y_i+1)\big)^2}$ | `=КОРЕНЬ(СРЗНАЧ(столбец_5))` |
| $R^2$ | $1-\dfrac{ESS}{TSS}$ | `=1-ESS/TSS` |
| $R^2_{adj}$ | $1-\dfrac{ESS/(n-k)}{TSS/(n-1)}$ | `=1-(ESS/(n-k))/(TSS/(n-1))` |
| AIC | $n\ln\dfrac{ESS}{n}+2k$ | `=n*LN(ESS/n)+2*k` |
| BIC | $n\ln\dfrac{ESS}{n}+k\ln n$ | `=n*LN(ESS/n)+k*LN(n)` |

## Шаг 2. Интерпретация
- MSE и RMSE сильнее всего реагируют на выбросы, потому что ошибка возводится в квадрат. RMSE измеряется в единицах $y$.
- MAE меньше зависит от выбросов. MAPE показывает ошибку в процентах от $y$; ориентир источников 10–15 % (в методичке по корреляции 8–10 %).
- RMSLE сглажена логарифмом и мало реагирует на большие $y$.
- AIC и BIC: лучше меньшее значение. Сравнивать можно только модели на одних и тех же данных, поэтому значения для выборок «с выбросами» и «без» напрямую сравнивать нельзя (разное $n$).
- $R^2$ не замечает выбросы, а $R^2_{adj}$ штрафует за лишние факторы.

## Шаг 3. Типичные ошибки
- Забыть заменить нули в $y$ (ломает MAPE).
- В BIC записать $k+\ln n$ вместо $k\ln n$ (так ошибочно в файле `Метрики качества модели.xlsx`).
- Брать $k$ без константы.
- Считать значения функциями AIC/BIC из statsmodels или R и сравнивать с ручными: они считаются через логарифм правдоподобия и отличаются на константу.

## Шаг 4. Проверка в Python
```python
import numpy as np
e = y - yhat
n, k = len(y), 3
ess = np.sum(e**2); tss = np.sum((y - y.mean())**2)
mse = ess/n; rmse = np.sqrt(mse); mae = np.mean(np.abs(e))
mape = 100*np.mean(np.abs(e/y))
rmsle = np.sqrt(np.mean((np.log(yhat+1) - np.log(y+1))**2))
r2 = 1 - ess/tss; r2a = 1 - (ess/(n-k))/(tss/(n-1))
aic = n*np.log(ess/n) + 2*k; bic = n*np.log(ess/n) + k*np.log(n)
```
Сверьте результат с таблицей; $R^2$ должен совпасть с `summary` регрессии.
