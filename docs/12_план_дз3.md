# План выполнения ДЗ 3

## Зачем это нужно
Одна страница: что требует каждый пункт ДЗ 3 и как оформлять результат по образцу из задания (SPSS, 58 стран). Срок (21.10) уже прошёл; план нужен как образец для п. 5 МР 1.

## Определения и обозначения
- 5–7 показателей $x$ по домохозяйствам своего региона (`TER`): например, доходные (сбережения `SSBER`, социальные пособия) и состава домохозяйства (число детей, пенсионеров, инвалидов, работающих `CHRAB`).
- ГК — главная компонента; $\lambda_j$ — её собственное значение; нагрузка — корреляция исходного показателя с компонентой.

## Теория: пункты задания и конспекты

| # | Что сделать | Конспект |
|---|---|---|
| 1 | Факторный анализ методом PCA. Обосновать число факторов: по собственному значению ГК (**приоритет**, $\lambda>1$), по доле объяснённой дисперсии, по графику «каменистой осыпи» | [08](08_метод_главных_компонент.md) |
| 2 | Состав факторов по матрице нагрузок; описательная характеристика (название) каждого фактора | [08](08_метод_главных_компонент.md) |
| 3 | График домохозяйств в пространстве двух факторов (3D при трёх факторах); вывод, какое сочетание факторов преобладает | [08](08_метод_главных_компонент.md) |
| 4 | Линейная регрессия на исходных $x$ и на главных компонентах; сравнить по $R^2$ и MSE | [08](08_метод_главных_компонент.md), [02](02_корреляция_и_парная_регрессия.md), [03](03_метрики_качества.md) |

## Алгоритм (по шагам)
1. Согласовать с пользователем регион, набор $x$ и зависимую переменную $y$ для п. 4 (в задании $y$ не названа).
2. Загрузить данные программно, отфильтровать по `TER`.
3. Описательные статистики (среднее, СКО, $n$).
4. Корреляционная матрица; собственные значения; доли дисперсии; scree plot.
5. Оставить компоненты с $\lambda>1$; сверить с долей дисперсии и «осыпью».
6. Матрица нагрузок (при желании — вращение), назвать факторы.
7. Сохранить значения факторов для каждого домохозяйства, построить диаграмму рассеяния.
8. Регрессия $y$ на исходные $x$ и на ГК; сравнить $R^2$ и MSE.

## Критерии и интерпретация
- Число факторов: $\lambda_j>1$ (приоритет), затем накопленная доля дисперсии, затем излом на графике «каменистой осыпи».
- Состав фактора: переменные с нагрузкой по модулю $>0{,}5$. Знак «+» и «−» описывают противоположные «концы» фактора.
- Описание «концов» фактора: на положительном конце — объекты с высокими значениями «+»-переменных и низкими «−»-переменных; название фактора даётся по смыслу группы переменных.
- Образец из задания (SPSS, 58 стран, 7 показателей): $\lambda_1=4{,}527$ (64,675 %), $\lambda_2=1{,}569$ (22,409 %), накопленно 87,084 % → 2 фактора; фактор 1 назван «уровень благосостояния», фактор 2 — «демографическая ситуация».
- Настройки SPSS из задания: Анализ → Снижение размерности → Факторный анализ; «Одномерные описательные»; «Матрица корреляций», «График собственных значений», «собственное значение выше 1»; вращение — любое или «Нет»; «Сохранить как переменные» для значений факторов.

> **Расхождение.** Заголовок задания упоминает «кластерного и факторного анализа», а перечень пунктов содержит только факторный анализ. Кластерный анализ в пунктах не требуется; уточнить у преподавателя, если нужен.
> **Нет в источнике.** Зависимая переменная $y$ для п. 4 в задании не указана — выбрать вместе с пользователем (например, расходы или доход, не входящие в набор $x$).
> **Нет в источнике.** В конспекте [08](08_метод_главных_компонент.md) нет выбора вращения (varimax и др.); в задании сказано лишь, что вращение улучшает распределение дисперсии между ГК и допускается любое или «Нет». Рекомендую «Нет» (проще, согласуется с конспектом 08); подтвердить у пользователя.
> **Нет в источнике.** Правило scree plot: в конспекте 08 отмечено отсутствие формального правила; в ДЗ 3 «осыпь» — вспомогательное обоснование.

## Пример
Образец вывода — Таблицы 1–3 в тексте задания (58 стран, 7 показателей); числа из задания, пересчитать их нельзя (исходных данных нет). Числовой разбор PCA — в [08](08_метод_главных_компонент.md).

## Реализация
Python (`sklearn.decomposition.PCA` на стандартизированных данных; для нагрузок — собственные векторы $\times\sqrt{\lambda}$) или R (`prcomp`, `scale=TRUE`); заготовки — в [08](08_метод_главных_компонент.md) и [09](09_инструменты_R.md).

## Типичные ошибки
- Не стандартизировать показатели в разных единицах (рубли и число детей).
- Оставлять компоненты по доле дисперсии вопреки правилу $\lambda>1$.
- Называть факторы без опоры на нагрузки.
- Сравнивать модели по $R^2$ без MSE (в задании требуются оба).
- Включать в $x$ показатели, линейно выражаемые друг через друга.
