# План выполнения ДЗ 2

## Зачем это нужно
Одна страница: что требует каждый пункт ДЗ 2, какой конспект читать, что положить в отчёт. Срок (07.10) уже прошёл; план нужен как образец для МР 1.

## Определения и обозначения
- $y$ — расходы (`USLUG`, `PROD` или `ALK`, на выбор); $x_1$ — `DOXODN` (среднедушевой денежный доход); $x_2$ — второй показатель (например, число детей до 16 лет, `CHDET`), по мнению автора **не влияющий** на $y$. Всего **два** $x$.
- Выборка: 150 наблюдений одного региона (`TER`), либо все домохозяйства региона.
- $\alpha = 0{,}05$.

## Теория: пункты задания и конспекты

| # | Что сделать | Конспект |
|---|---|---|
| 0 | Выбрать регион по `TER` (первые 2 цифры ОКАТО), регионы в группе не повторяются; нули в $y$ заменить единицами | [02](02_корреляция_и_парная_регрессия.md) |
| 1 | Значимость уравнения в целом: $H_0:\beta_1=\dots=\beta_n=0$ ($F$-тест) | [02](02_корреляция_и_парная_регрессия.md) |
| 2 | Значимость параметров ($t$-тест) для коэффициентов и свободного члена; словесный вывод про каждый | [02](02_корреляция_и_парная_регрессия.md) |
| 3 | Объясняющая способность — $R^2$ | [02](02_корреляция_и_парная_регрессия.md), [03](03_метрики_качества.md) |
| 4 | Очистка исходных $x$ и $y$ от выбросов по межквартильному размаху («ящик с усами»); повторить пп. 1–3; сравнить значимость модели, коэффициенты и $R^2$ до/после | [05](05_выбросы.md) |
| 4а | Содержательные выводы по взаимодействию показателей в регионе | [02](02_корреляция_и_парная_регрессия.md) |
| 5 | **Вручную** (не готовой функцией), для данных с выбросами и без: MSE, RMSE, MAE, MAPE, RMSLE, $R^2$ и $R^2_{adj}$ через остатки, AIC, BIC; вывод, как изменились самые чувствительные к выбросам метрики | [03](03_метрики_качества.md) |
| 6 | По желанию: логарифмировать обе части ($\ln y=b_0+b_1\ln x_1+b_2\ln x_2$), посчитать $R^2$ | [02](02_корреляция_и_парная_регрессия.md) |

Пп. 1–4 можно делать в любой программе; п. 5 — вручную, потом сверить с программой.

## Алгоритм (по шагам)
1. Уточнить у пользователя регион и $y$; не угадывать по `организация/`.
2. Загрузить данные программно, отфильтровать по `TER`, не читая файл целиком.
3. Заменить нули в $y$ на единицы (нужно и для $\ln y$, и для MAPE/RMSLE).
4. Построить регрессию, проверить $F$, $t$, $R^2$.
5. Найти выбросы по IQR в $x_1$, $x_2$ и $y$, удалить, пересчитать.
6. Рассчитать метрики п. 5 вручную для обеих выборок; свести в таблицу «с выбросами / без».
7. (Опц.) Лог-лог модель; сравнить только по $R^2$.
8. Написать выводы.

## Критерии и интерпретация
- Схема каждого вывода: $H_0$/$H_1$ → статистика → правило ($p<0{,}05$ ⇒ отвергаем $H_0$) → словесный вывод.
- Незначимый коэффициент ⇒ нет оснований считать, что $y$ зависит от этого $x$ (в генеральной совокупности коэффициент может быть 0). Незначимый свободный член ⇒ принимаем, что он равен 0 в генеральной совокупности.
- После логарифмирования $b_1,b_2$ — эластичности (на сколько % изменится $y$ при изменении $x$ на 1% при среднем значении другого $x$); коэффициенты до и после логарифмирования **не сравнивать**, модели сравнивать только по $R^2$.
- AIC: лучшая модель — с наименьшим значением. BIC: предпочтительна модель с наименьшим значением (баланс качества и простоты).

> **Нет в источнике.** В задании не указано, что делать с выбросами в $x_2$, если он дискретный (число детей): боксплот может «видеть» выбросы в значениях 4–5. Решить вместе с пользователем и зафиксировать в отчёте.
> **Нет в источнике.** Правило «из двух $x$ один не должен влиять на $y$» — проверка лишь по смыслу; формально это проверяется незначимостью $t$-теста для этого $x$.

## Типичные ошибки
- Считать метрики п. 5 готовой функцией.
- Забыть заменить нули в $y$ (ломает MAPE и логарифм).
- Сравнивать коэффициенты линейной и лог-лог моделей.
- Чистить выбросы только по $y$, а не по всем исходным $x$ и $y$.
- Давать таблицу без словесного вывода.
