# Дополнения к МР 1

> **Нет в источнике.** Весь конспект восполняет пробелы, помеченные в [10](10_план_мр1.md), [02](02_корреляция_и_парная_регрессия.md), [03](03_метрики_качества.md) как «Нет в источнике». Это общепринятая теория и мои формулы, в материалах курса их нет. Пункты про R² для $\ln y$ и PP-график согласовать с УА или преподавателем.

## Зачем это нужно
Задание МР 1 требует QQ/PP-графики, сравнение моделей с $\ln y$ и без него, анализ влияния и регуляризацию, а конспекты 02–08 этого не разбирают. Здесь собраны недостающие формулы и правила.

## Определения и обозначения
- $e_i$ — остаток, $z_i$ — стандартизированный остаток, $e_{(i)}$ — упорядоченные остатки; $\Phi$ — функция распределения $N(0,1)$.
- $n$ — число наблюдений, $k$ — число параметров вместе с константой.
- $h_{ii}$ — рычаг; $D_i$ — расстояние Кука; $DW$ — статистика Дарбина–Уотсона.
- $V_k$ — матрица первых $k$ собственных векторов (PCA), $\gamma$ — коэффициенты регрессии на главных компонентах.

## Теория

### 1. QQ- и PP-графики
- **QQ.** Пары $\big(\Phi^{-1}\!\big(\tfrac{i-0{,}5}{n}\big),\ z_{(i)}\big)$: теоретические квантили против упорядоченных стандартизированных остатков. Точки на диагонали — остатки нормальны; S-образный изгиб — тяжёлые хвосты; дуга — асимметрия.
- **PP.** Пары $\big(\Phi(z_{(i)}),\ \tfrac{i-0{,}5}{n}\big)$: теоретическая против эмпирической функции распределения. Диагональ — согласие. PP чувствительнее в центре распределения, QQ — в хвостах.
- При большом $n$ формальные тесты нормальности (Шапиро–Уилка, Жарка–Бера) почти всегда отвергают $H_0$. Опираться на графики; для $t$ и $F$ при большом $n$ нормальность не критична.

### 2. $R^2$ для моделей с $\ln y$
Сравнивать $R^2$ можно только при одинаковой форме $y$. Для $\ln y$ пересчёт в исходные единицы:
$$\hat y_i=\exp(\widehat{\ln y_i}),\qquad R^2_{\text{пересч}}=1-\frac{\sum (y_i-\hat y_i)^2}{\sum (y_i-\bar y)^2}.$$
Альтернатива: $R^2=\big(\operatorname{corr}(y,\hat y)\big)^2$. Результаты близки, но не равны; выбрать один способ и указать его в отчёте.

Простое $\exp$ слегка занижает прогноз. Поправка Дуана (smearing): $\hat y_i=\exp(\widehat{\ln y_i})\cdot\tfrac1n\sum_j e^{e_j}$. Для МР 1 достаточно простого $\exp$ с оговоркой.
Модель по $\ln y$ сравнивать с моделью по $y$ только по RMSE/MAE/$R^2$ в исходных единицах. AIC/BIC и остаточную дисперсию напрямую сравнивать нельзя.

### 3. Интерпретация коэффициентов при преобразованиях

| Модель | Смысл $b$ |
|---|---|
| $y=b_0+b_1x$ | $+1$ ед. $x$ → $y$ меняется на $b_1$ ед. |
| $y=b_0+b_1\ln x$ | $+1\,\%$ $x$ → $y$ меняется на $\approx b_1/100$ ед. |
| $\ln y=b_0+b_1x$ | $+1$ ед. $x$ → $y$ меняется на $\approx 100\,b_1\,\%$ (точно $100(e^{b_1}-1)\,\%$) |
| $\ln y=b_0+b_1\ln x$ | $+1\,\%$ $x$ → $y$ меняется на $b_1\,\%$ (эластичность) |
| бинарная $d$, $y$ без логарифма | группа $d=1$ отличается на $b$ ед. |
| бинарная $d$, $\ln y$ | группа $d=1$ отличается на $100(e^{b}-1)\,\%$ при прочих равных |

Логарифмировать можно только положительные значения. Нули либо исключают, либо используют $\ln(1+x)$ — оговорить в отчёте. Бинарные переменные и счётчики с нулями не логарифмируют.

### 4. Автокорреляция остатков
Критерии выбора модели в задании требуют независимости остатков. У микроданных домохозяйств порядок строк произвольный, содержательной автокорреляции нет.
$$DW=\frac{\sum_{i=2}^n (e_i-e_{i-1})^2}{\sum_{i=1}^n e_i^2}\approx 2(1-\hat\rho).$$
Значение около 2 — автокорреляции нет. В отчёте написать, что данные кросс-секционные и $DW$ приведён формально.

### 5. Гипотеза и бинарные переменные
- Шаблон: $H_0:\beta_j=0$ против $H_1:\beta_j\ne0$ (или $>0$, $<0$ по ожидаемому знаку); $t=b_j/se_j$; отвергаем $H_0$, если $|t|>t_{0{,}975;\,n-k}$ ($p<0{,}05$).
- Вывод словами: знак, величина, единицы, содержательный смысл.
- Категориальная переменная с $c$ уровнями → $c-1$ дамми (иначе «ловушка дамми»: точная коллинеарность с константой).
- Доля бинарных: 20 % от 5 — это 1; при 6–7 переменных брать 2 (округление вверх). Это моя трактовка, согласовать с УА.

### 6. Регуляризация: нюансы
- Стандартизировать $x$ (включая бинарные) **до** штрафа, иначе вес в штрафе зависит от единиц измерения.
- Разбить данные на train и test (например, 80/20, фиксированный `random_state`). CV подбирает $\lambda$ на train; качество OLS и всех регуляризованных моделей сравнивать на **одном и том же** test.
- У регуляризованных моделей нет $p$-значений и стандартных ошибок; интерпретация идёт по знакам, величинам и обнулению коэффициентов. Это главный минус перед OLS.
- Elastic Net: подбирать и $\lambda$, и `l1_ratio`; в [07](07_мультиколлинеарность_и_регуляризация.md) рассмотрен только $\alpha=0{,}5$.
- Остатки выбранной модели: $e=y-\hat y$, стандартизировать самостоятельно; готовых стьюдентизированных остатков у `sklearn` нет.

### 7. PCA: нюансы
- Считать по стандартизированным $x$, без $y$.
- Бинарные переменные в PCA формально допустимы, но интерпретация ГК усложняется — оговорить в отчёте.
- Нагрузки для интерпретации: $|\text{нагрузка}|\ge 0{,}4$–$0{,}5$.
- Коэффициенты в исходных переменных: $\beta_x=V_k\gamma$ (для стандартизированных $x$). Это позволяет сравнить с OLS и интерпретировать влияние каждого $x$.
- ГК ортогональны, VIF между ними равен 1.

### 8. Влияние и выбросы
Дополнительно к стандартизированным и стьюдентизированным остаткам ([05](05_выбросы.md)):
- рычаг $h_{ii}$: порог $2k/n$;
- расстояние Кука $D_i$: порог $4/n$ (или $>1$);
- $|t_i|>2$ (или $>3$) — выброс по стьюдентизированному остатку.

Выбросы не удалять молча: показать модель до и после очистки и сравнить коэффициенты.

## Алгоритм (по шагам)
1. Построить OLS, получить остатки, QQ- и PP-графики, остатки против $\hat y$.
2. Посчитать влияние ($h_{ii}$, $D_i$, внешние стьюдентизированные остатки); при очистке сравнить до и после.
3. Для моделей с $\ln y$ пересчитать $\hat y$ и $R^2$ в исходные единицы перед сравнением.
4. Вывести $DW$ формально, оговорить кросс-секционность.
5. Регуляризацию строить на стандартизированных $x$, train/test, подбор $\lambda$ по CV; метрики на одном test.
6. В PCA после регрессии на ГК вернуть коэффициенты к исходным переменным: $\beta_x=V_k\gamma$.

## Критерии и интерпретация
$\alpha=0{,}05$. Для нормальности остатков — графики QQ/PP как основной аргумент; для гомоскедастичности — тесты из [06](06_гетероскедастичность.md); для влияния — пороги выше.

## Реализация
```python
import numpy as np, statsmodels.api as sm, scipy.stats as st
from statsmodels.stats.stattools import durbin_watson

# res = sm.OLS(y, X).fit()
e = res.resid; z = (e - e.mean()) / e.std(ddof=1)
sm.qqplot(z, line="45")                       # QQ
sm.ProbPlot(z).ppplot(line="45")              # PP
st.shapiro(e); st.jarque_bera(e)              # формальные тесты (по желанию)
durbin_watson(e)                              # DW

inf = res.get_influence()
inf.resid_studentized_internal                # стандартизированные
inf.resid_studentized_external                # стьюдентизированные
inf.hat_matrix_diag                           # рычаги
inf.cooks_distance[0]                         # расстояние Кука

# R^2 для ln y в исходных единицах
y_hat = np.exp(res_ln.fittedvalues)
r2 = 1 - ((y - y_hat)**2).sum() / ((y - y.mean())**2).sum()
```

## Типичные ошибки
- Сравнивать $R^2$ моделей с $y$ и $\ln y$ без пересчёта.
- Логарифмировать бинарные переменные и нули.
- Не стандартизировать $x$ перед Ridge/Lasso/Elastic Net.
- Сравнивать OLS на всей выборке с регуляризованными моделями на test.
- Включать все уровни категориальной переменной вместе с константой.
- Молча удалять выбросы.
- Писать выводы по QQ/PP только по формальным тестам нормальности.
