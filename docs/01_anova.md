# Дисперсионный анализ (ANOVA)

## Зачем это нужно
Ответить на вопрос «различаются ли средние в трёх и более группах или различия случайны». $t$-критерий сравнивает только две группы; ANOVA делает это одним тестом и не копит ошибку множества попарных сравнений. Тот же принцип «общая вариация = объяснённая + остаточная» лежит в основе $F$-теста регрессии ([02](02_корреляция_и_парная_регрессия.md)).

## Определения и обозначения
- $v$ (в слайдах также $l$) — число вариантов (групп, уровней фактора); $n$ — повторность варианта (при равной повторности); $n_i$ — объём $i$-й группы; $N=\sum n_i$ ($=vn$) — всего наблюдений.
- $x_{ij}$ — $j$-е наблюдение в $i$-й группе; $\bar x_i$ — среднее группы; $\bar x$ — общее среднее; $V_i=\sum_j x_{ij}$ — сумма по группе; $X=\sum V_i$ — общая сумма.
- $C$ — корректирующий фактор (поправка); СКО — общая сумма квадратов; СК$_V$ — между вариантами; СК$_E$ — остаточная (случайная, «ошибка»).
- $S^2_V$, $S^2_E$ — средние квадраты (дисперсии); $F$ — критерий Фишера.
- НСР — наименьшая существенная разность; $S_d$ — ошибка разности средних; $S_{\bar x}$ — ошибка средней.
- $\eta^2$ — эмпирический коэффициент детерминации, $\eta$ — эмпирическое корреляционное отношение.

## Теория

### Общая вариация раскладывается на две части
Общая вариация = вариация между вариантами (действие изучаемого фактора) + случайная вариация (неизучаемые факторы, «шум»). Одновременно раскладываются суммы квадратов и степени свободы:
$$\text{СКО}=\text{СК}_V+\text{СК}_E,\qquad N-1=(v-1)+(N-v).$$

### Это правило сложения дисперсий
В терминах дисперсий (деление на $N$, как в семинарской таблице):
$$D_{общ}=D_{мг}+D_{вг},$$
где $D_{мг}=\frac1N\sum n_i(\bar x_i-\bar x)^2$ — межгрупповая (за счёт группировочного признака), $D_{вг}=\frac1N\sum n_i\sigma_i^2$ — средняя из внутригрупповых (за счёт прочих факторов), $\sigma_i^2$ — дисперсия внутри группы (делитель $n_i$). $D_{общ}=\overline{x^2}-\bar x^2$.

### Рабочие формулы сумм квадратов
$$C=\frac{X^2}{N},\quad \text{СКО}=\sum x_{ij}^2-C,\quad \text{СК}_V=\frac{\sum V_i^2}{n}-C,\quad \text{СК}_E=\text{СКО}-\text{СК}_V.$$
При разной повторности $\text{СК}_V=\sum\frac{V_i^2}{n_i}-C$ (так в `ANOVA.xlsx`, лист «ДА», блок Б).

### $F$-критерий — отношение дисперсий
$$S^2_V=\frac{\text{СК}_V}{v-1},\qquad S^2_E=\frac{\text{СК}_E}{N-v},\qquad F=\frac{S^2_V}{S^2_E}.$$
Сравнивается с $F_{05}$ (или $F_{01}$) при $df_1=v-1$, $df_2=N-v$.

### Сила влияния фактора
Доля вариации, объяснённая фактором: $\text{СК}_V/\text{СКО}$. В терминах семинара — эмпирический коэффициент детерминации и корреляционное отношение:
$$\eta^2=\frac{D_{мг}}{D_{общ}},\qquad \eta=\sqrt{\eta^2}.$$
Шкала Чеддока для $\eta$ (из семинарского файла): 0–0,3 слабая; 0,3–0,5 средне-слабая; 0,5–0,7 средняя; 0,7–0,9 сильная; $\eta=1$ — линейная связь. $D_{мг}=0$ — группы не влияют; $D_{мг}=D_{вг}$ — приведено в файле как опорная точка.

### Какие группы различаются: НСР
Если $F\ge F_{05}$, гипотеза о равенстве средних отвергается, и средние сравнивают попарно по НСР:
$$S_{\bar x}=\sqrt{\frac{S^2_E}{n}},\quad S_d=\sqrt{\frac{2S^2_E}{n}},\quad \text{НСР}_{05}=t_{05}\,S_d,$$
$t_{05}$ берётся при $df=N-v$. Разность $|d|\ge\text{НСР}$ существенна ($*$ при 5 %, $**$ при 1 %). Для сравнения со стандартом (контролем) $d=\bar x_{оп}-\bar x_{st}$; три группы по знаку: $d\ge$ НСР — существенное превышение, $|d|<$ НСР — несущественно, $-d\ge$ НСР — существенное снижение.

При неравной повторности ошибка разности считается для каждой пары по её $n_i,n_j$ (в файле — отдельные НСР для разных пар).

### Другие множественные сравнения
В слайдах перечислены: Фишер НСР (LSD), Бонферрони, Шеффе, Тьюки (по $q\cdot S_{\bar x}$), Дункан (НСР умножается на поправку $C$, зависящую от ранга $r$: 1,0; 1,05; 1,08; 1,09 для $r=2..5$), Дуннет (сравнение с контролем). Для сравнения «опытных с контрольным» берут Дуннета.

### Двухфакторный ANOVA с повторениями
Две факторные переменные $A$ ($a$ уровней) и $B$ ($b$ уровней), в каждой ячейке $r$ повторений. Вариация раскладывается на фактор $A$, фактор $B$, их взаимодействие и остаток:
$$\text{СКО}=\text{СК}_A+\text{СК}_B+\text{СК}_{AB}+\text{СК}_E,$$
$$df:\ N-1=(a-1)+(b-1)+(a-1)(b-1)+ab(r-1).$$
Каждый $F$ (для $A$, $B$, $AB$) = средний квадрат эффекта / $S^2_E$. Значимое взаимодействие $AB$ означает, что влияние одного фактора зависит от уровня другого.

> **Нет в источнике.** Формулы $\text{СК}_A$, $\text{СК}_B$, $\text{СК}_{AB}$ в слайде 18 лежат картинкой и текстом не извлекаются; в `Двухфакторный ANOVA.xlsx` стоят готовые значения из «Пакета анализа» Excel. Выше записана только структура разложения; формулы не выводились. При необходимости использовать Excel «Двухфакторный анализ с повторениями» или `statsmodels`.

### Предпосылки ANOVA (слайды)
1. Ошибки случайны, независимы и распределены нормально.
2. Нет корреляции между дисперсиями и средними по вариантам.
3. Однородность дисперсий вариантов (тест Бартлетта; Кохрена — при равной повторности).
4. Аддитивность эффектов (тест Тьюки).

При нарушении однородности (дисперсия растёт со средним) данные преобразуют: $\sqrt X$, $\lg X$, $\arcsin\sqrt X$ (для долей), выполняют ANOVA на преобразованных значениях, сравнивают средние по НСР и возвращаются к исходным средним (слайды 37–40).

### Критерий Кохрена — равенство дисперсий при одинаковом числе наблюдений
Для $N$ групп с одинаковым числом параллельных наблюдений:
$$G=\frac{S^2_{max}}{\sum_{i=1}^{N}S_i^2}.$$
Excel: `=МАКС(диапазон)/СУММ(диапазон)`. Сравнивают с $G_{кр}$ при $\alpha=0{,}05$, числе дисперсий $N$ и $f=n-1$. Если $G\le G_{кр}$ — дисперсии однородны. Иначе — проверить данные на промахи, исключить подозрительную группу и повторить. При разном числе наблюдений предлагается критерий Бартлетта (в источнике только таблица критических точек $\chi^2$-типа для $f=1..10$: 3,8; 6; 7,8; 9,5; 11,1; 12,6; 14,1; 15,5; 16,9; 18,3 — это квантили $\chi^2$ при $\alpha=0{,}05$, формула статистики в источнике не приведена).

> **Нет в источнике.** Формула статистики Бартлетта не приведена (только таблица квантилей). Не использовать по этому конспекту.

### Критерий Краскела-Уоллиса — когда нет нормальности
Непараметрический аналог однофакторного ANOVA: сравнивает не средние, а ранги. Порядок: все $N$ значений ранжируют вместе (одинаковым значениям — средний ранг), считают сумму и средний ранг $\bar R_i$ каждой группы, общий средний ранг $\bar R=\frac{N+1}{2}$,
$$H=\frac{12}{N(N+1)}\sum_i n_i(\bar R_i-\bar R)^2 ,\qquad df=k-1,$$
и сравнивают $H$ с $\chi^2_{05}(df)$ (так в `Критерий Краскера-Уолиса.xlsx`: `=G12*(12/(13*14))`, `=CHIINV(0,05;2)`). $H>\chi^2_{кр}$ — различия между группами значимы. Условия: ≥3 независимые группы, порядковая или непрерывная шкала, независимые наблюдения, формы распределения групп одинаковые; желательно ≥5 наблюдений в группе. В SPSS: «Непараметрические критерии → для K независимых выборок».

### Распределение Фишера
$F$-распределение несимметрично, принимает значения $\ge0$, зависит от пары степеней свободы $(n_1,n_2)$ — числителя и знаменателя. Таблица в источнике даёт $F_{табл}$: $P(F>F_{табл})$ = 0,05; 0,01; 0,001. В Excel: `F.ОБР.ПХ(0,05; df1; df2)`; $p$-значение — `F.РАСП.ПХ(F; df1; df2)`.

> **Расхождение.** В `Распределение Фишера .pdf` значения столбца $n_1=5$ при $n_2\ge2$ выглядят испорченными (например $F_{05}(5;5)$ в таблице 4,45, а пересчёт даёт 5,05; $F_{05}(5;10)$: 2,94 против 3,33). Остальные столбцы ($n_1=1,2,3,4,6,8,12,24,\infty$) в выборочной проверке совпали с пересчётом. Столбец $n_1=5$ не использовать — считать $F_{кр}$ функцией.

## Алгоритм (по шагам)
1. Сформулировать $H_0$: $\mu_1=\dots=\mu_v$.
2. Рабочая таблица: суммы $V_i$ и средние по группам, общая сумма.
3. $N$, $C$, СКО, СК$_V$, СК$_E$.
4. Таблица ANOVA: источник, СК, $df$, $S^2$, $F$, $F_{05}$.
5. Если $F<F_{05}$ — стоп. Иначе НСР и сравнение средних (со стандартом или между собой).
6. Проверить предпосылки (Кохрен/Бартлетт, нормальность); при нарушении — преобразование или Краскел-Уоллис.
7. Сформулировать вывод словами и указать долю влияния фактора.

## Критерии и интерпретация
- $H_0$: все генеральные средние равны, различия случайны; $H_1$: хотя бы одно среднее отличается.
- Статистика $F=S^2_V/S^2_E$ с $(v-1;N-v)$ степенями свободы.
- Правило при $\alpha=0{,}05$: $F\ge F_{05}$ (или $p<0{,}05$) ⇒ $H_0$ отвергаем.
- Словами: «влияние фактора на результативный признак статистически значимо на 5 % уровне; на его долю приходится …% общей вариации». Затем НСР: какие именно варианты отличаются.

## Пример
Источник: `Семинар 1_ANOVA.pptx`, слайды 22–30: урожайность 5 сортов озимой пшеницы, $v=5$, $n=4$, $N=20$. Пересчитано кодом (Python/`scipy.stats.f_oneway`), совпало:

| Источник | СК | $df$ | $S^2$ | $F$ | $F_{05}$ |
|---|---|---|---|---|---|
| Общая | 352,6 | 19 | – | – | – |
| Варианты | 302,9 (85,9 %) | 4 | 75,72 | 22,86 | 3,06 |
| Остаток | 49,7 (14,1 %) | 15 | 3,31 | – | – |

$C=31768{,}4$. $F=22{,}86>3{,}06$ ⇒ сорта различаются. $S_d=\sqrt{2\cdot3{,}31/4}=1{,}29$; $\text{НСР}_{05}=2{,}13\cdot1{,}29\approx2{,}7$; $\text{НСР}_{01}\approx3{,}8$ (пересчёт: 2,74 и 3,79). Сравнение со стандартом «Безостая 1» (36,2): Золушка $d=3{,}2^*$, Дельта $-0{,}5$ (незначимо), Сфера $5{,}4^{**}$, Престиж $10{,}1^{**}$.

> **Расхождение.** Слайд 33 считает НСР по $t_{05}=2{,}18$ ($df=12$) и $S_d=1{,}13$ и получает 2,5, а слайды 26–34 (и пересчёт) дают $df=15$, $S_d=1{,}29$ и НСР $\approx2{,}7$. Использовать вариант с $df=N-v=15$: слайд 33 внутренне противоречив.

Дополнительные примеры из источников (все числа пересчитаны):
- `Семинар_1_17_09…xlsx`, «Разложение дисперсии» (цена бензина, 3 марки, $N=14$): $D_{общ}=56{,}72=D_{мг}+D_{вг}=51{,}22+5{,}50$; $\eta^2=0{,}903$, $\eta=0{,}950$ — тесное влияние марки.
- `Критерий Краскера-Уолиса.xlsx` (затраты на связь, 3 возрастные группы, $N=13$): $H=6{,}40>\chi^2_{05}(2)=5{,}99$ ⇒ группы различаются. С поправкой на совпадающие ранги `scipy.stats.kruskal` даёт 6,42; в файле поправки на ничьи нет.
- `Двухфакторный ANOVA.xlsx` (урожайность, густота × доза навоза, по 5 повторений в 9 ячейках): фактор $A$ $F=3{,}69>3{,}26$ ($p=0{,}035$) — значим; фактор $B$ $F=0{,}0008$ и $AB$ $F=0{,}012$ — незначимы. Пересчитано `statsmodels`, совпало.
- Критерий Кохрена (`…Кохрана…стр. 12.pdf`): $G=0{,}162$, $G_{кр}(N=9,f=9)=0{,}2659$ ⇒ дисперсии однородны. (Исходных данных для пересчёта в источнике нет; табличное 0,2659 в приложении 2 совпадает.)

## Реализация
Excel: «Данные → Анализ данных → Однофакторный дисперсионный анализ» (и двухфакторный с повторениями); `F.ОБР.ПХ`, `СТЬЮДЕНТ.ОБР.2Х`, `ХИ2.ОБР.ПХ`.
```python
from scipy import stats
F, p = stats.f_oneway(g1, g2, g3)      # однофакторный
H, p = stats.kruskal(g1, g2, g3)       # Краскел-Уоллис
# двухфакторный: statsmodels
import statsmodels.api as sm
from statsmodels.formula.api import ols
sm.stats.anova_lm(ols('y ~ C(A)*C(B)', df).fit(), typ=2)
```
R: `summary(aov(y ~ g, data))`, `kruskal.test(y ~ g, data)`.

## Типичные ошибки
- Делать много попарных $t$-тестов вместо ANOVA + НСР.
- Объявлять «различия есть» без НСР/пост-теста: значимый $F$ не говорит, какие именно группы различаются.
- Не проверять однородность дисперсий (Кохрен) и нормальность.
- Путать $df_{E}$: это $N-v$, а не $v(n-1)$ только при равной повторности.
- Брать $F_{кр}$ из таблицы с битым столбцом ($n_1=5$) вместо функции.
- Применять формулу Краскела-Уоллиса без учёта, что она сравнивает ранги, а не средние.
