# Выбросы и диагностика остатков

## Зачем это нужно
Один-два нетипичных объекта могут сместить линию регрессии и исказить коэффициенты. Нужно найти их до построения модели (IQR по одной переменной) и после (по остаткам модели) и решить, что с ними делать. Это часть пунктов 2, 3 и 4 МР 1: график стандартизированных и стьюдентизированных остатков для диагностики влияния.

## Определения и обозначения
- $Q_1,Q_3$ — первый и третий квартили; $IQR=Q_3-Q_1$.
- $LF=Q_1-1{,}5\,IQR$, $UF=Q_3+1{,}5\,IQR$ — нижняя и верхняя границы («усы»).
- $e_i=y_i-\hat y_i$ — остаток; $s=\sqrt{ESS/(n-k)}$ — стандартная ошибка регрессии, $k$ — число параметров вместе с константой.
- $H=X(X^\top X)^{-1}X^\top$ — матрица рычагов («шляпная»), $h_{ii}$ — её диагональный элемент (рычаг наблюдения $i$).

## Теория

### Два вида выбросов
- **Вертикальный** — нетипичное $y$ при обычном $x$. Меняет форму связи и сразу влияет на $R^2$.
- **Горизонтальный** — нетипичное $x$ (рычаг). Меняет коэффициент регрессии: линия «тянется» к такой точке.
- Выброс по $y$ и по $x$ одновременно сдвигает тренд сильнее всего.
- Большое значение MAPE у объекта — повод проверить, не выброс ли он ([метрики](03_метрики_качества.md)).

### Правило IQR (одна переменная)
Наблюдение — выброс, если
$$x_i<LF=Q_1-1{,}5\,IQR\quad\text{или}\quad x_i>UF=Q_3+1{,}5\,IQR .$$
Если $LF<0$, а данные отрицательными быть не могут, то выбросами считаются только значения выше $UF$.

### Рычаги
$h_{ii}$ показывает, насколько $x$-значения объекта $i$ далеки от центра выборки, т. е. насколько он способен «тянуть» линию. Всегда $\sum h_{ii}=k$.

> **Нет в источнике.** Порога для $h_{ii}$ в материалах нет. Общепринятое правило — смотреть на $h_{ii}>2k/n$ (в примере ниже $2\cdot3/20=0{,}3$); помечено для проверки у преподавателя.

### Четыре вида остатков
| название в источнике | формула | смысл |
|---|---|---|
| остаток | $e_i$ | в единицах $y$ |
| стандартные (шкалированные) | $e_i/SD(e)$, $SD$ — стандартное отклонение остатков | как в выводе Excel |
| стандартизированные | $\dfrac{e_i}{s\sqrt{1-h_{ii}}}$ | учитывают рычаг: у объектов с большим $h_{ii}$ остаток по построению мал, и формула это компенсирует |
| стьюдентизированные (формула источника) | $\dfrac{e_i}{SD(e)\sqrt{1-h_{ii}}}$ | вариант из файла |

Общее правило чтения: $|{\rm остаток}|>2$ — подозрительное наблюдение, $>3$ — вероятный выброс (**нет в источнике**, общепринятые ориентиры; помечено для проверки у преподавателя).

> **Расхождение.** В файле «Расчет стандартизированных (стьюдентизированных) остатков.xlsx» стьюдентизированные остатки считаются как $e_i/(SD(e)\sqrt{1-h_{ii}})$, где $SD(e)$ — стандартное отклонение всех остатков. В учебной литературе и в `statsmodels` (`resid_studentized_external`) знаменатель содержит $s_{(-i)}$ — стандартную ошибку регрессии, **посчитанную без $i$-го наблюдения**. Для наблюдения 7 из примера: источник 2,547, классическое внешнее стьюдентизированное 2,880 (пересчёт кодом). В МР 1 использовать, какой вариант разрешит преподаватель; в отчёте указать формулу.
> Ещё замечание: в файле ссылки на ячейки $h_{ii}$ в разных строках записаны непоследовательно, поэтому я сверял значения с пересчётом, а не формулы.

## Алгоритм (по шагам)
1. Для каждой количественной переменной: $Q_1,Q_3,IQR,LF,UF$; отметить значения за границами. Боксплот показывает то же самое.
2. Построить модель, посчитать остатки $e_i$ и $h_{ii}=\operatorname{diag}\big(X(X^\top X)^{-1}X^\top\big)$.
3. Посчитать стандартизированные и стьюдентизированные остатки; построить график остатков по номеру или по $\hat y$ с линиями $\pm2$ и $\pm3$.
4. Для найденных объектов проверить, не ошибка ли это данных, вернуться к смыслу (богатое домохозяйство — не ошибка).
5. Построить модель с выбросами и без них; сравнить $R^2$, коэффициенты, их значимость. Решение (удалить, логарифмировать, оставить) обосновать.

## Критерии и интерпретация
Формального теста нет: решение за исследователем. Рабочая интерпретация:
- выброс по IQR → смотреть, влияет ли он на коэффициенты (сравнить две модели);
- большой $|$остаток$|$ при малом $h_{ii}$ → вертикальный выброс; большой $h_{ii}$ → горизонтальный (рычаг);
- логарифмирование сжимает хвост распределения и часто снимает «выбросы» у доходов и расходов (см. [план МР 1](10_план_мр1.md)).

Как сказать словами: «по правилу IQR 229 из 2150 значений ($\approx10{,}7\%$) превышают $UF=57\,604$; нижняя граница отрицательна, поэтому нижних выбросов нет».

## Пример
**IQR** (`Расчет выбросов_IQR.xlsx`, затраты на корма, тыс. руб., 2150 наблюдений). Пересчитано кодом по данным из файла:

| величина | значение |
|---|---|
| $Q_1$ / $Q_3$ | 3569,75 / 25183,5 |
| $IQR$ | 21613,75 |
| $LF$ / $UF$ | −28850,875 / 57604,125 |
| выбросов (> $UF$) | 229 (в файле тоже 229) |
| медиана / максимум | 9941 / 5 635 609 |

Квартили в файле считаются Excel-функцией `КВАРТИЛЬ` (включающий метод, как `numpy.percentile` по умолчанию).

**Остатки** (`Расчет стандартизированных…xlsx`, $n=20$, $y$ на $x_1,x_2$, $k=3$, $s=1{,}5216$), наблюдение 7: $e=3{,}540$, $h=0{,}0672$; стандартизированный остаток $2{,}409$ (совпадает с файлом), «стьюдентизированный» по файлу $2{,}547$, внешний стьюдентизированный по литературе $2{,}880$. Наибольший рычаг в выборке $0{,}722$ при пороге $0{,}3$ — это горизонтальный выброс.

## Реализация
```python
import numpy as np, statsmodels.api as sm
m = sm.OLS(y, sm.add_constant(X)).fit()
infl = m.get_influence()
h = infl.hat_matrix_diag                       # рычаги
r_int = infl.resid_studentized_internal        # стандартизированные e/(s*sqrt(1-h))
r_ext = infl.resid_studentized_external        # стьюдентизированные (литература)
q1, q3 = np.percentile(x, [25, 75]); iqr = q3 - q1
mask = (x < q1 - 1.5*iqr) | (x > q3 + 1.5*iqr)
```
R: `hatvalues(model)`, `rstandard(model)`, `rstudent(model)`, `boxplot.stats(x)$out`. Excel: `КВАРТИЛЬ`, `МОБР`, `МУМНОЖ`, `ТРАНСП` (как в файле).

## Типичные ошибки
- Удалять выбросы, не посмотрев, ошибка ли это данных.
- Применять IQR к бинарной переменной.
- Не учитывать, что $LF<0$ для неотрицательных данных.
- Путать вертикальный и горизонтальный выброс: первый портит $R^2$, второй — коэффициент.
- Смотреть только на $R^2$: он выбросы «не ловит».
