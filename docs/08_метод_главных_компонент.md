# Метод главных компонент (PCA)

## Зачем это нужно
Когда объясняющие переменные сильно коррелированы, их можно заменить меньшим числом **некоррелированных** комбинаций, сохранив почти всю информацию. Регрессия на таких комбинациях не страдает от мультиколлинеарности. Это пункт 5 МР 1: взять компоненты, объясняющие не менее 70 % дисперсии, интерпретировать каждую, построить по ним регрессию и оценить качество.

## Определения и обозначения
- $x_1,\dots,x_p$ — исходные количественные переменные ($y$ в PCA не участвует: это обучение без учителя).
- $Z$ — стандартизированные переменные $z=(x-\bar x)/SD_x$: после стандартизации среднее 0, дисперсия 1.
- $R$ — корреляционная матрица $Z$ (для стандартизированных данных совпадает с ковариационной); $C$ — ковариационная матрица центрированных данных, $C=\dfrac{A^\top A}{n-1}$, где $A$ — центрированные данные.
- $\lambda_1\ge\lambda_2\ge\dots\ge\lambda_p$ — собственные числа; $v_j$ — собственные векторы; $PC_j$ (ГК $j$) — главные компоненты.
- $a_{ij}$ — факторная нагрузка (вес переменной $i$ в компоненте $j$).

## Теория

### Идея
1. Ищем направление, вдоль которого дисперсия данных наибольшая — это первая компонента; затем ортогональное ему направление с наибольшей оставшейся дисперсией — вторая; и т. д. Число компонент равно числу переменных.
2. Чем больше дисперсия, тем больше «информации» несёт компонента.
3. Переменные **стандартизируют**, чтобы масштаб не диктовал вес (после стандартизации дисперсии выровнены).
4. Собственное число $\lambda_j$ — дисперсия, обусловленная $j$-й компонентой. При стандартизации сумма $\sum\lambda_j=p$ (числу переменных).
5. Доля компоненты: $\dfrac{\lambda_j}{\sum\lambda_l}$; накопленная доля — сумма первых $m$ долей.

### Алгебра
Собственные числа $C$ (или $R$) находятся из характеристического уравнения
$$\det(C-\lambda I)=0,$$
собственный вектор $v$ — из $(C-\lambda I)v=0$ при условии $\|v\|=1$. Значение компоненты для объекта $i$: $PC_{ij}=v_j^\top z_i$ (скалярное произведение вектора на центрированный/стандартизированный объект).
Разложение переменной по компонентам: $z_i=\sum_\nu a_{i\nu}f_\nu$, где $f_\nu$ — значение $\nu$-й компоненты.

### Выбор числа компонент
Берут первые $m$ компонент так, чтобы их суммарный вклад превышал **60–70 %** (источник); в МР 1 требуется **не менее 70 %**.

### Регрессия на главных компонентах
Объясняющие переменные заменяются значениями первых $m$ компонент:
$$y=b_0+b_1PC_1+\dots+b_mPC_m+\varepsilon .$$
Компоненты ортогональны, признаки некоррелированы — **мультиколлинеарности нет**. Коэффициенты $b_j$ оцениваются обычным МНК.

### Факторные нагрузки и интерпретация
Матрица нагрузок — коэффициенты корреляции компонент с исходными переменными. Интерпретация компоненты: какие переменные вносят основной вклад (большие по модулю нагрузки) и в какую сторону (знак). Знак у собственного вектора определён с точностью до умножения на $-1$ — не ошибка, а свойство метода. Практическое применение — факторный анализ: число факторов задаёт исследователь.

### Расхождения и пробелы в источнике
> **Расхождение.** В `РСА_пример 3.xlsx` собственный вектор считается по **округлённому** $\lambda_1=8{,}855$ (точное значение 8,8503), поэтому $PC_1=-0{,}947x_1+0{,}324x_2$ вместо точного $-0{,}9467x_1+0{,}3220x_2$, значения компоненты немного отличаются (например, объект 1: 2,542 против 2,537). Это погрешность округления; использовать точные значения из пересчёта.
> **Расхождение.** В `РСА_пример 2.xlsx` итоговая строка `pc1 = -0,8503x1 - 2,5x2 - 2,5x1 - 7,3503x2` — это запись системы $(C-\lambda I)v=0$, а не готовая формула компоненты. Решение системы — как в примере 3.
> **Нет в источнике.** В материалах нет формулы возврата коэффициентов $b_j$ в исходные переменные и правила выбора числа компонент по графику «каменистой осыпи»; для МР 1 они не требуются.

## Алгоритм (по шагам)
1. Взять только количественные объясняющие переменные (бинарные переменные в PCA обычно не включают — **нет в источнике**, оговорить в отчёте; при включении PCA считается формально, но интерпретация сложнее).
2. Стандартизировать: $z=(x-\bar x)/SD_x$ (или хотя бы центрировать).
3. Посчитать ковариационную/корреляционную матрицу, собственные числа и векторы.
4. Посчитать доли дисперсии $\lambda_j/p$ и накопленные доли; выбрать $m$ по порогу 70 %.
5. Посчитать нагрузки (корреляции компонент с переменными), назвать каждую компоненту по тем переменным, что вносят основной вклад.
6. Посчитать значения компонент для всех объектов и построить регрессию $y$ на них; оценить $R^2$, $F$, $t$ (см. [регрессия](02_корреляция_и_парная_регрессия.md)).
7. Интерпретировать: как рост компоненты (с учётом знака нагрузок) влияет на $y$.

## Критерии и интерпретация
Формального теста нет; критерий — накопленная доля дисперсии ($\ge70\%$ в МР 1). Значимость компонент в регрессии — обычные $F$ и $t$ при $\alpha=0{,}05$. Важно: $R^2$ регрессии на **всех** $p$ компонентах равен $R^2$ исходной модели (проверено кодом: 0,5314), на меньшем числе компонент — ниже. Платой за устранение мультиколлинеарности является потеря интерпретируемости отдельных $x$.

Как сказать словами: «первая компонента (61 % дисперсии) объединяет $x_1,x_2,x_3$ — показатели технической оснащённости; все нагрузки отрицательны, поэтому рост оснащённости снижает значение $PC_1$, а отрицательный $b_{PC_1}$ означает, что урожайность при этом растёт».

## Пример
**1. Две переменные** (`PCA_пример 1.xlsx`, $n=5$: $x_1=3,6,8,2,7$; $x_2=4,5,9,3,6$; значения восстановлены из файла). Пересчёт кодом: $r=0{,}9062$, для $2\times2$ матрицы $\lambda_{1,2}=1\pm r$: $\lambda_1=1{,}9062$, $\lambda_2=0{,}0938$, доли $95{,}3\%$ и $4{,}7\%$ (совпадает с файлом); $v_1=(0{,}7071;\ 0{,}7071)$, нагрузки первой компоненты $0{,}976$ у обеих переменных. Сумма $\lambda_1+\lambda_2=2=p$.

**2. Точное решение для центрированных данных** (`РСА_пример 3.xlsx`: $x_1=0,0,0,4,6$; $x_2=3,1,1,0,0$). $C=\begin{pmatrix}8&-2{,}5\\-2{,}5&1{,}5\end{pmatrix}$, $\lambda_1=8{,}8503$, $\lambda_2=0{,}6497$, доли $93{,}2\%$ и $6{,}8\%$; $v_1=(-0{,}9467;\ 0{,}3220)$ (пересчёт кодом).

**3. Регрессия на компонентах** (мой расчёт на данных $n=20$, 5 факторов из `Метрики качества модели.xlsx`; **не из источника**, иллюстрация): стандартизированные $x_1..x_5$; $\lambda=(3{,}052;\ 1{,}395;\ 0{,}430;\ 0{,}112;\ 0{,}012)$, доли $61{,}0\%;\ 27{,}9\%;\ 8{,}6\%;\ 2{,}2\%;\ 0{,}2\%$, накопленно $61{,}0\%;\ 88{,}9\%$ → для порога 70 % нужны **две** компоненты. Нагрузки (знаки условны):

| | $PC_1$ | $PC_2$ |
|---|---|---|
| $x_1$ | −0,949 | 0,208 |
| $x_2$ | −0,931 | 0,180 |
| $x_3$ | −0,945 | 0,265 |
| $x_4$ | −0,251 | −0,881 |
| $x_5$ | −0,573 | −0,687 |

$PC_1$ — «общий уровень» $x_1,x_2,x_3$ (механизация), $PC_2$ — в основном $x_4$ и $x_5$ (удобрения и химзащита). Регрессия $y$ на $PC_1,PC_2$: $R^2=0{,}348$, $R^2_{adj}=0{,}271$, $F=4{,}53$ ($p=0{,}027$); $b_{PC_1}=-0{,}544$ ($p=0{,}025$), $b_{PC_2}=-0{,}569$ ($p=0{,}100$). Знак $b$ при $PC$ читается вместе со знаком нагрузок: у $PC_1$ все нагрузки отрицательны, значит рост $x_1,x_2,x_3$ **уменьшает** $PC_1$, а при $b_{PC_1}<0$ это повышает $y$; у $PC_2$ нагрузка $x_4$ тоже отрицательна ($-0{,}881$), и при $b_{PC_2}<0$ рост $x_4$ повышает $y$ (но $PC_2$ незначима на уровне 5 %). Выводы согласуются с положительными парными $r(y,x)$.
Здесь PCA заметно ухудшила $R^2$ по сравнению с моделью на всех $x$ (0,531): уменьшив число переменных, мы потеряли часть объяснённой дисперсии $y$ — компоненты выбираются по дисперсии $x$, а не по связи с $y$.

## Реализация
```python
import numpy as np, statsmodels.api as sm
Z = (X - X.mean(0)) / X.std(0, ddof=1)             # стандартизация
R = np.corrcoef(Z.T)
w, v = np.linalg.eigh(R); w, v = w[::-1], v[:, ::-1]   # по убыванию
share = w / w.sum(); cum = share.cumsum()
m = int(np.searchsorted(cum, 0.70) + 1)            # число ГК для порога 70%
loadings = v * np.sqrt(w)                           # корреляции ГК с переменными
scores = Z @ v[:, :m]
res = sm.OLS(y, sm.add_constant(scores)).fit()
```
`sklearn.decomposition.PCA(n_components=0.70).fit(Z)` делает то же самое (`explained_variance_ratio_`). R: `prcomp(x, scale. = TRUE)`, `summary(pc)` (доли дисперсии), `pc$rotation` (векторы), `pc$x` (значения компонент). Excel: `МОПРЕД`, `МУМНОЖ`, `ТРАНСП` (как в файлах примеров), собственные значения — решением характеристического уравнения.

## Типичные ошибки
- Не стандартизировать переменные разных масштабов.
- Включать в PCA зависимую переменную $y$.
- Интерпретировать знак компоненты как «положительное влияние», не посмотрев на знак нагрузок.
- Считать, что компоненты с большой дисперсией $x$ обязательно сильнее связаны с $y$.
- Брать число компонент равным $p$ и называть это снижением размерности.
- Использовать округлённые $\lambda$ при расчёте собственных векторов.
