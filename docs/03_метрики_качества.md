# Метрики качества модели

## Зачем это нужно
Одним числом ответить «насколько прогноз модели близок к фактам» и сравнить несколько моделей (с логарифмами, с Ridge/Lasso, на главных компонентах). Нужно для пунктов 3, 4 и 8 МР 1.

## Определения и обозначения
- $y_i$ — факт, $\hat y_i$ — прогноз, $e_i=y_i-\hat y_i$; $n$ — число наблюдений; $k$ — число параметров **включая константу** (в примере 5 факторов + константа → $k=6$).
- $ESS=\sum e_i^2$ — сумма квадратов остатков; $TSS=\sum(y_i-\bar y)^2$ — полная сумма квадратов.

## Теория

### Метрики ошибки (чем меньше, тем лучше)
| метрика | формула | заметки из источника |
|---|---|---|
| MSE | $\frac1n\sum e_i^2$ | в квадрате единиц $y$; чувствительна к выбросам (большие ошибки штрафуются сильнее, модель «подстраивается» под выброс) |
| RMSE | $\sqrt{MSE}$ | в единицах $y$; если RMSE заметно ниже $\bar y$, качество хорошее |
| MAE | $\frac1n\sum\lvert e_i\rvert$ | в единицах $y$; к выбросам нечувствительна, минимизировать сложнее |
| MAPE | $\frac{100\%}{n}\sum\left\lvert\frac{y_i-\hat y_i}{y_i}\right\rvert$ | оптимум 10–15 % для всей модели; большая доля у объекта → вероятно выброс; растёт при нулях и малых $y$ |
| RMSLE | $\sqrt{\frac1n\sum\left(\ln(\hat y_i+1)-\ln(y_i+1)\right)^2}$ | сглаживает влияние больших $y$, нечувствительна к выбросам по $y$; «+1» нужно, чтобы не брать логарифм нуля |

Источник также считает «MAE по наивному прогнозу»: наивный прогноз для объекта $i$ — предыдущее значение $y_{i-1}$, для первого объекта ошибка берётся равной ошибке модели. Отношение $MAE_{модели}/MAE_{наивн}$ показывает, лучше ли модель наивного прогноза (меньше 1 — лучше).

> **Расхождение.** В файле метрик ячейка «MAE» содержит **отношение** $MAE_{модели}/MAE_{наивн}=0{,}4859$, а сама MAE модели равна $1{,}0483$ (ячейка M32). Для отчёта: MAE = 1,048; $0{,}486$ — относительная ошибка к наивному прогнозу.

> **Расхождение.** Ориентир для MAPE в `docx` метрик — 10–15 %, в методичке по корреляции (средняя ошибка аппроксимации) — 8–10 %. В отчёте указывать, каким порогом пользуешься.

### $R^2$ и скорректированный $R^2$
$$R^2=1-\frac{ESS}{TSS},\qquad R^2_{adj}=1-\frac{ESS/(n-k)}{TSS/(n-1)} .$$
- Ориентир источника: $R^2$ около 0,6–0,7.
- При матричной оценке без константы $R^2$ может быть отрицательным: модель хуже, чем простое среднее.
- $R^2$ **не ловит выбросы**: он может быть высоким при наличии выбросов.
- Низкий $R^2$ говорит об отсутствии *линейной* связи, но не о том, что связи нет.
- Для моделей с разным числом факторов сравнивать надо $R^2_{adj}$.

### Информационные критерии (минимизируются)
$$AIC=n\ln\frac{ESS}{n}+2k,\qquad BIC=n\ln\frac{ESS}{n}+k\ln n .$$
Самостоятельной интерпретации у значения нет, критерии нужны только для **сравнения** моделей на одних и тех же данных; штраф за число факторов у BIC сильнее при $\ln n>2$ (т. е. $n>7$).

> **Расхождение.** В `Метрики качества модели.xlsx` ячейка BIC содержит формулу `n*LN(ESS/n)+k+LN(n)` (значение 20,046), тогда как подпись рядом и `docx` дают $n\ln(ESS/n)+k\ln n$. Пересчёт кодом: AIC $=23{,}0505$ (совпадает), BIC по верной формуле $=29{,}0249$. Использовать $29{,}02$.
> Библиотеки (statsmodels) считают AIC/BIC через логарифм правдоподобия, значения другие (79,8 и 85,8); сравнивать модели можно только внутри одного способа расчёта.

### Выбросы и метрики
- Вертикальный выброс (по $y$) меняет форму связи и сразу ухудшает $R^2$; горизонтальный (по $x$) тянет за собой коэффициент регрессии. Подробнее — [выбросы](05_выбросы.md).
- Признаки нелинейности: низкий $R^2_{adj}$, автокорреляция остатков, результаты RESET, AIC, BIC.

## Алгоритм (по шагам)
1. Получить прогноз $\hat y$ (в тех же единицах, что и факт).
2. Посчитать $e_i$, затем MSE, RMSE, MAE, MAPE ($y=0$ заменить на малое положительное или исключить; в ДЗ 2 нули заменяются единицами).
3. Посчитать $ESS$, $TSS$, $R^2$, $R^2_{adj}$, AIC, BIC.
4. Для логарифмированного $y$ вернуть прогноз в исходные единицы и считать метрики ошибки по исходному $y$, иначе их нельзя сравнивать с моделями без логарифма.
5. Сравнить модели по таблице метрик; решение принимать вместе со значимостью параметров и остатками, а не по одной метрике.

> **Нет в источнике.** Явного правила для обратного преобразования $\widehat{\ln y}\to\hat y$ в материалах нет (простое $\exp$ даёт слегка смещённый прогноз). Для МР 1 достаточно $\exp(\cdot)$ и оговорки.

## Критерии и интерпретация
Формального статистического теста нет, выводы строятся сравнением:
- модель лучше, если ниже RMSE/MAE/MAPE и AIC/BIC, выше $R^2_{adj}$;
- MAPE 10–15 % — приемлемо; выше — модель плохо описывает отдельные объекты, искать выбросы;
- $R^2$ мало отличается от $R^2_{adj}$ → лишних факторов немного; большой разрыв → в модели лишние переменные.

## Пример
`Метрики качества модели.xlsx`, $n=20$, $k=6$ (значения пересчитаны кодом, совпадают с файлом):

| метрика | значение |
|---|---|
| MSE | 1,7376 |
| RMSE | 1,3182 ($\bar y=9{,}525$) |
| MAE | 1,0483 |
| MAPE | 10,75 % |
| RMSLE | 0,1176 |
| $ESS$ / $TSS$ | 34,7528 / 74,1575 |
| $R^2$ / $R^2_{adj}$ | 0,5314 / 0,3640 |
| AIC / BIC | 23,05 / 29,02 (в файле BIC ошибочно 20,05) |
| $F$ / $F_{крит}$ | 3,175 / 2,958 |

Вывод: MAPE на границе приемлемого, $R^2$ немного ниже ориентира 0,6, а разрыв между $R^2$ и $R^2_{adj}$ (0,53 → 0,36) говорит о лишних признаках.

## Реализация
```python
import numpy as np
e = y - yhat
mse = np.mean(e**2); rmse = np.sqrt(mse); mae = np.mean(np.abs(e))
mape = np.mean(np.abs(e / y)) * 100
rmsle = np.sqrt(np.mean((np.log1p(yhat) - np.log1p(y))**2))
ess = np.sum(e**2); tss = np.sum((y - y.mean())**2)
r2 = 1 - ess/tss; r2_adj = 1 - (ess/(n-k)) / (tss/(n-1))
aic = n*np.log(ess/n) + 2*k; bic = n*np.log(ess/n) + k*np.log(n)
```
Excel: `СРЗНАЧ`, `КОРЕНЬ`, `СУММКВРАЗН`, `LN`; в R — `summary(lm)$r.squared`, `AIC(model)`, `BIC(model)` (значения другого вида, чем формулы выше).

## Типичные ошибки
- Считать BIC как $k+\ln n$ (ошибка файла) вместо $k\ln n$.
- Сравнивать RMSE модели по $\ln y$ и модели по $y$.
- Считать MAPE при нулевых $y$.
- Выбирать модель только по $R^2$ при разном числе факторов.
- Сравнивать AIC/BIC, посчитанные разными способами.
