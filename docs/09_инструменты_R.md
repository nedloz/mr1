# Инструменты R

## Зачем это нужно
Справочник функций, которыми в материалах курса выполняются расчёты МР 1: корреляция, регрессия, диагностика остатков, робастные ошибки, Ridge/Lasso/Elastic Net. Если задание допускает несколько инструментов, использовать тот, что назвал пользователь; в окружении проекта R может быть не установлен, тогда те же расчёты делаются на Python (см. блоки «Реализация» в других конспектах).

## Определения и обозначения
- `data` — таблица данных (`read_excel("файл.xlsx")` из пакета `readxl`); `y` — зависимая переменная; `x` — матрица факторов; `model` — объект `lm`.

## Теория

### Базовые функции
| задача | функция | где в курсе |
|---|---|---|
| корреляция, ковариация | `cor(x, y)`, `cov(x, y)` (на примере: 0,4303 и 1,8068) | [02](02_корреляция_и_парная_регрессия.md) |
| регрессия | `lm(y ~ x1 + x2, data = data)`; `summary(model)` — коэффициенты, $t$, $p$, $R^2$, $F$ (аналог ANOVA регрессии) | [02](02_корреляция_и_парная_регрессия.md) |
| сравнение короткой и длинной модели | `anova(model_restricted, model_unrestricted)` — $F$-тест вложенных моделей | [02](02_корреляция_и_парная_регрессия.md) |
| ридж | `MASS::lm.ridge(y ~ x + z, lambda = 2, data = data)` | [07](07_мультиколлинеарность_и_регуляризация.md) |
| лассо / ridge / EN | `glmnet::cv.glmnet(x, y, alpha = 1 / 0 / 0.5)`, `$lambda.min`, `glmnet(..., lambda = best)`, `coef(...)` | [07](07_мультиколлинеарность_и_регуляризация.md) |

Лассо в источнике запускается на числовой матрице: `x <- data.matrix(data[, c('x1','x2')])`; `cv.glmnet` требует именно матрицу, а не `data.frame`.

### Тесты на гетероскедастичность и робастные ошибки (пакеты)
| тест | пакет и функция | результат на данных примера |
|---|---|---|
| Бройша–Пагана | `lmtest::bptest(model)` | $BP=5{,}611$, $df=5$, $p=0{,}3459$ |
| Уайта | `whitestrap::white_test(model)` | 3,32, $p=0{,}1897$ |
| Голдфелда–Квандта | `lmtest::gqtest(model)` | $GQ=1{,}905$, $p=0{,}2739$ |
| Глейзера | `skedastic::glejser(model)` | 7,68, $p=0{,}175$ |
| Спирмена | `strucchange::spearman_test`(?) | в источнике «не сработал» |
| робастные ошибки | `sandwich::vcovHC(model, type = "HC0"…"HC3")` | `sqrt(diag(vcovHC(...)))` — робастные $se$ |

Значения проверены пересчётом на Python (подробнее — [06](06_гетероскедастичность.md)); Спирмена считать вручную по формуле.

> **Расхождение.** В файле «Основные функции в R.docx» раздел назван «Тест Уайта на гетероскедастичность», а код под ним — это `sandwich` и **тест Вальда** для сравнения вложенных моделей (`Wald test … F = 0,0079`), а не тест Уайта. Для White использовать `whitestrap::white_test` (см. файл «Коды_Семинар 6»).
> **Нет в источнике.** Как подставить робастную матрицу в `summary` (пакет `lmtest::coeftest(model, vcov = vcovHC(model, type = "HC0"))`) в материалах не показано, там даны только сами $se$. Функция `coeftest` — стандартная, помечена для проверки.

## Алгоритм (по шагам)
Типовой порядок для МР 1 на R:
1. `install.packages(c("readxl","lmtest","sandwich","whitestrap","glmnet","MASS"))`, `library(...)`.
2. `data <- read_excel(...)`; `cor(data)`; графики.
3. `model <- lm(y ~ ., data)`; `summary(model)`.
4. `bptest`, `white_test`, `gqtest`; `vcovHC` и `coeftest` при гетероскедастичности.
5. `cv.glmnet` для трёх значений `alpha`; `predict`, `coef`, MSE.
6. `prcomp(x, scale. = TRUE)` для PCA и регрессия `lm(y ~ pc$x[,1:m])`.

## Критерии и интерпретация
Для всех тестов: $p<0{,}05$ → нулевая гипотеза отвергается. Вывод о гомо-/гетероскедастичности подписан рядом с результатом в «Коды_Семинар 6» (ручными пометками «гомоскедастичность»).

## Пример
Вывод R из «Коды_Семинар 6» для 5-факторной модели на данных из файла метрик: $R^2=0{,}5314$, $R^2_{adj}=0{,}364$, $F=3{,}175$ на $(5;14)$, $p=0{,}04016$; остаточная стандартная ошибка $1{,}576$ на 14 степенях свободы. Значимо только $x_4$ ($t=2{,}989$, $p=0{,}00977$). Совпадает с Excel и с пересчётом на Python ([02](02_корреляция_и_парная_регрессия.md)).

## Реализация
```r
library(lmtest); library(sandwich); library(whitestrap); library(glmnet)
model <- lm(y ~ x, data = Data)
summary(model)
bptest(model); white_test(model); gqtest(model)
robust_se <- sqrt(diag(vcovHC(model, type = "HC0")))
coeftest(model, vcov = vcovHC(model, type = "HC0"))   # t, p по робастным ошибкам
```

## Типичные ошибки
- Подавать `data.frame` в `glmnet` вместо матрицы.
- В `lm(y ~ x)`, где `x` — матрица, названия коэффициентов получают префикс `x` (`xx1`): это не ошибка.
- Сравнивать $\lambda$ из `lm.ridge`, `glmnet` и Stata без учёта масштабирования.
- Путать `anova(model1, model2)` ($F$-тест вложенных моделей) с «ANOVA одного фактора».
