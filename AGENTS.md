## О проекте

Учебный проект по курсу «Моделирование статистических зависимостей» (МИЭМ, 2026).
Цель: выполнять домашние задания (ДЗ) и модульные работы (МР), одновременно изучая методы.
Язык материалов и ответов — русский.

## Структура репозитория

| Путь                    | Содержимое                                                                                                                                                                   |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `docs/`                   | Теория в формате Markdown — основной источник знаний для агентов. Индекс: `docs/README.md`, шаблон: `docs/_template.md` |
| `теория/`           | Исходные материалы курса (docx, xlsx, pptx, pdf, R-скрипты), по темам 1–7, плюс `инструменты_R/` и `литература/`    |
| `ДЗ/ДЗ_1 … ДЗ_4/`  | Задания и решения домашних работ                                                                                                                           |
| `МР/МР_1, МР_2/`    | Задания и решения модульных работ                                                                                                                         |
| `данные/`           | Микроданные бюджетов домохозяйств 2023 (`Доходы домохозяйств_2023.xlsx`, ~40 МБ) и описание переменных         |
| `организация/` | Ведомость и распределение регионов (персональные данные студентов)                                                           |
| `_дубликаты/`    | Побайтовые копии файлов из `теория/`; не использовать                                                                                     |

## Как работать с теорией

1. Сначала читай `docs/`, а не исходные файлы. Если нужной темы там нет (статус `todo`), прочитай источники из `теория/` и напиши конспект по `docs/_template.md`.
2. Один файл — одна тема, имя `NN_название.md`; новый файл сразу добавляй в таблицу `docs/README.md`.
3. Формулы — в LaTeX (`$…$`, `$$…$$`). Скриншоты формул не использовать.
4. Каждое утверждение должно сверяться с источником. Не придумывай формулы и числовые примеры по памяти: если источник неясен или расходится с общепринятым, пометь это в тексте блоком «Расхождение» и сообщи пользователю.
5. Не копируй источники целиком: конспект должен быть самодостаточным, но короче оригинала. В `sources` указывай путь до исходного файла.
6. Принятый уровень значимости — $\alpha = 0{,}05$, если задание не требует другого.

## Как работать с заданиями

- Перед началом прочитай текст задания в `ДЗ/…` или `МР/…` и соответствующие конспекты в `docs/`.
- Решение кладётся рядом с заданием (`ДЗ/ДЗ_N/` или `МР/МР_N/`): расчёты, датасет, отчёт.
- Регион для ДЗ выбирается по коду `TER` (первые две цифры ОКАТО). Для МР 1 нужен другой регион, чем для ДЗ, но из того же файла данных. Конкретный регион пользователя уточняй у него, не угадывай по `организация/`.
- По ДЗ 2: нулевые значения $y$ заменяются единицами; ошибки (MSE, RMSE, MAE, MAPE) считаются вручную, а не готовой функцией.
- Для ДЗ и МР нужно не только получить числа, но и сформулировать вывод: что значимо, как изменилось после очистки выбросов, как интерпретируются коэффициенты.
- Большой файл `данные/Доходы домохозяйств_2023.xlsx` не читай целиком в контекст: загружай программно и фильтруй по `ter`.

## Ограничения

- Исходные файлы не удалять, не переименовывать и не изменять; новые файлы создавать рядом.
- Файлы из `организация/` содержат ФИО и баллы студентов: не копировать их содержимое в `docs/`, отчёты и коммиты.
- Промежуточные файлы и скрипты, не относящиеся к результату, не складывать в `ДЗ/` и `МР/`.
- Если задание допускает несколько способов (Excel, R, Python, SPSS), используй тот, который назвал пользователь; по умолчанию — Python или R со сверкой ключевых чисел вручную.
